GNSS code multipath · Rust core · Python API

Measure multipath. Map where it comes from.

geoveil-mp reads RINEX 2, 3 and 4 and estimates code multipath for every pseudorange signal on GPS, GLONASS, Galileo, BeiDou, QZSS and NavIC, with cycle slips detected per carrier. Version 1.0 adds SNR wavelet analysis and first Fresnel zone mapping, so the numbers point back to the ground that caused them.

MethodAnubis / TEQC style

From observables to reflectors

Two processing lanes share one parsed file. The code lane measures how much multipath each signal carries. The SNR lane finds its periods and the Fresnel step places it around the antenna.

MPk = Pk − (1 + 2/(α−1)) Φi + (2/(α−1)) Φj,   α = (fi / fj)² Φi is the phase on the code's own band, Φj a partner band from a fixed per-system priority list. GLONASS uses each satellite's channel number from the header.

Code multipath

  1. Parse RINEX 2, 3 or 4 into code, phase and SNR per satellite and epoch.
  2. Form MPk for every pseudorange code with a deterministic phase pairing.
  3. Detect cycle slips with geometry-free, code-phase and loss-of-lock tests whose thresholds scale with the interval.
  4. Remove the ambiguity bias per arc, resetting at gaps, slips and jumps.
  5. Report per signal: RMS, elevation-weighted RMS and slip counts, with elevations from SP3 or broadcast orbits.

SNR and reflectors new

  1. Pick the band-1 S observable for each satellite.
  2. Convert dB-Hz to linear amplitude and split into arcs at gaps.
  3. Detrend each arc with the polynomial of order 2 to 9 that leaves the smallest residual.
  4. Run the Morlet transform and average power into four period bands, with red-noise significance.
  5. Place first Fresnel zones along each track for your antenna height and carrier.

Five lines to a station report

Install from PyPI, point it at a RINEX file, and read plain Python lists and dicts back. The Rust crate exposes the same functions.

import geoveil_mp as gm

obs = gm.read_rinex_obs("HAR100ROU_R_20253650000_01D_30S_MO.rnx")

# Code multipath and cycle slips per signal
res = gm.MultipathAnalyzer(obs, 10.0, ["G", "R", "E"]).analyze()
for s in res.statistics:
    print(s.signal, round(s.rms, 3), s.cycle_slips)   # GLOM3Q 0.395 ...

# New in 1.0: SNR wavelets for every satellite, in parallel
w = gm.analyze_snr_wavelets(obs)
w["bands"]                       # [[60, 120], [120, 300], [300, 900], [900, 1800]]
w["band_power"]["R02"]["power"]  # binned power, one series per band

r = w["residuals"]["R02"]
scal = gm.scalogram(r["t"], r["v"], w["interval"])   # power, significance, coi

# First Fresnel zone for a 2 m antenna at 15° elevation, GPS L1
a, b, dist = gm.fresnel_zone(15.0, 2.0)                    # (4.896, 1.267, 7.464) m
use geoveil_mp::analysis::advanced::{fresnel_zone, morlet_cwt, snr_wavelets, SnrWaveletConfig, DJ, DEFAULT_WAVELENGTH};
use geoveil_mp::RinexObsReader;

let obs = RinexObsReader::new().read("HAR100ROU_R_20253650000_01D_30S_MO.rnx")?;

// SNR wavelets for all satellites (rayon-parallel)
let sats = snr_wavelets(&obs, &[], None, &SnrWaveletConfig::default());

// Band power of one residual series
let cwt = morlet_cwt(&sats[0].residual, 30.0, DJ, None);
let power = cwt.band_power((120.0, 300.0));

// First Fresnel zone: a, b and distance in metres
let z = fresnel_zone(15.0, 2.0, DEFAULT_WAVELENGTH);
